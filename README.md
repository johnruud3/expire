# Expire

One app for food dates — parted into **Family** and **Business** accounts. Home kjøleskap stay private. Wholesale shelves stay at work.

Norwegian and English. Local-first. Cloud invites come later.

## Run

```powershell
npm install
npx expo start
```

Open it in **Expo Go** on your iPhone (same Wi‑Fi), or press `w` for web.



## New test builds

Run from the project folder (`d:\expire\expire`). Wait until Expo says **Finished**, then open the build page and tap **Install**.

- Android:

```powershell
npx eas-cli@latest build --platform android --profile preview
```

- iPhone:

```powershell
npx eas-cli@latest build --platform ios --profile preview
```

- Both at once:

```powershell
npx eas-cli@latest build --platform all --profile preview
```
